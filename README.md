# Transcriptor de audios

Repositorio con la habilidad (skill) de Claude Code `transcripcion-literal-audio`, para transcribir grabaciones palabra por palabra, con marcas explícitas de incertidumbre y sin inventar contenido.

- Definición: [`.claude/skills/transcripcion-literal-audio/SKILL.md`](.claude/skills/transcripcion-literal-audio/SKILL.md)

## Uso

Abre una sesión de Claude Code en este repositorio, adjunta o indica un archivo de audio (mp3, m4a, wav, ogg, flac, aac, opus, webm, mp4) y pide que lo transcriba. La habilidad se activa automáticamente.
